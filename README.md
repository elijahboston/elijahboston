### side projects

🔨 **[TypeAnvil](https://github.com/whitelodge-esoteric/typeanvil)**: an open-source HTML → PDF typesetting engine written in Rust. You give it HTML plus paged-media CSS and get print-quality PDFs back (reports, invoices, books), with no headless-browser farm or $3,800-per-server license. Same input, byte-identical output, so you can diff-test documents in CI.

☸️ **[k8pm](https://github.com/k8pm/k8pm)**: a Kubernetes package manager where your cluster setup is TypeScript instead of piles of YAML. Your editor, type checker, and tests do the guarding.

📈 **[kalshi-bot](https://github.com/elijahboston/kalshi-bot)**: a terminal trading agent for Kalshi's climate prediction markets. It pulls weather forecasts (NWS + GEFS), estimates odds, sizes bets with Kelly, and tracks its own calibration. It only ever paper-traded and is now archived, but it's a good reference for building one.
